UberSDR Dial · Web Flasher

Guition JC3636K518C / JC3636K718

Flash the UberSDR Dial firmware straight from your browser with ESP Web Tools. No drivers, Python or PlatformIO needed: just Chrome or Edge and a USB-C cable.

1 · Wi-Fi (optional)

Your Wi-Fi network
Fill these in and the dial joins your network on first boot. It needs Wi-Fi for Receiver mode; Controller mode (Bluetooth or USB) doesn't. Leave them blank to set Wi-Fi up later from the dial's setup hotspot.
🔒 Your Wi-Fi details never leave this computer. They're added to the flash image here in the browser and written over USB, and the dial erases them from that spot in flash once it has saved them on first boot.

2 · Flash

UberSDR Dial
Guition JC3636K518C, also sold as JC3636K718 (ESP32-S3) · firmware + your Wi-Fi settings
⚠️ Web Serial isn't available in this browser.
Open this page in Google Chrome or Microsoft Edge (desktop, version 89+). Firefox and Safari don't support Web Serial.
⚠️ Web Serial needs a secure context (HTTPS).
Serve this page over https://; opening the file from disk (file://) won't work.
  1. Plug the dial into this computer with a USB-C data cable.
  2. Enter your Wi-Fi details above, or leave them blank.
  3. Click Connect, pick the port that appears (USB JTAG/serial debug unit), and follow the prompts.
  4. On a first install, Erase device is recommended. It also clears any settings saved on the dial.
⚠️ No port listed? The cable may be charge-only: try another. Close anything else using the port too, such as a serial monitor. The dial uses the ESP32-S3's built-in USB, so it needs no driver, and the flasher normally resets it into download mode by itself.
⚠️ Still no port, or "Failed to initialize"? Put the dial into download mode by hand. This is needed if the firmware on it has crashed or never finished flashing.
  1. Switch the dial off.
  2. Push a pin (a SIM tool or straightened paper clip) into the small hole next to the USB-C port, and keep it held down. That's the BOOT button.
  3. With the pin still held, switch the dial on, then let go.
The screen stays dark: that's expected. Click Connect and pick the port. After flashing, switch the dial off and on again.

After flashing

  1. The dial restarts and asks which mode to use: Receiver (Wi-Fi), or Controller over Bluetooth or USB.
  2. Receiver: with Wi-Fi baked in, the dial joins your network and lists receivers. Local receivers come first, then public ones. Pick one and tap Listen.
  3. No Wi-Fi baked in? The dial starts a hotspot called UberSDR-Dial-XXXX. Join it from a phone and the setup page opens (or browse to http://192.168.4.1/). Pick your network from the list and enter its password.
  4. Controller: open the UberSDR v2 web UI in Chrome or Edge, go to SDR Control → Dial, choose Bluetooth or USB to match the dial, and connect.
